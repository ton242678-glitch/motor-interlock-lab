ONE PROBLEM, ONE EXPERIMENT

两个方向，
只允许一个输出。

从一个电机出发，看懂正反转互锁、停机换向和急停后的主动恢复。

实验目标

先正常运行，
再主动制造一次冲突。

浏览器模型 · 不连接设备

电机与输送带

待使能
■ 停止

互锁成立：两个方向输出不会同时为 1。

操作台

点击命令保持，停止命令清除

先点击使能，然后选择一个方向。

01 / 正常运行

先停，再换向

使能 → 正转 → 停止 → 反转。直接换向会被拦截，当前方向保持。

02 / 方向互锁

冲突时全关断

同时请求两个方向 → 两个输出为 0 → 复位 → 使能。停止命令不能清除锁定。

03 / 急停锁存

解除后不自启

运行 → 急停 → 解除急停 → 复位 → 使能 → 主动启动。

04 / 过程追踪

让每次操作可见

对照输入、输出和事件记录，验证互锁条件。最近 100 步可以导出 CSV。
